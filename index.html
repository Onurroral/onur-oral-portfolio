Hakkımda

Bilgisayar Teknolojisi bölümünden 2,92 ortalama ile başarıyla mezun oldum. Öğrencilik ve geliştirme sürecimde React Native, JavaScript, HTML, CSS ve Three.js gibi teknolojilere odaklandım. Problem çözme becerimle yeni nesil kütüphaneleri projelerime hızlıca adapte edebiliyorum. Kendi mobil oyunumu sıfırdan geliştirerek bu süreçte büyük bir tecrübe edindim. Disiplinli çalışmaya ve kendimi sürekli geliştirmeye odaklıyım.

Projeler

BlockPop (Mobil Bulmaca Oyunu) 🚀

Bireysel olarak geliştirip yayınladığım blok bulmaca oyunu. İlk aşamada HTML, CSS ve JavaScript kullanılarak WebView tabanlı (Capacitor ile) inşa edilen oyun, sürükle-bırak hassasiyeti ve yüksek performanslı animasyonlar elde etmek amacıyla tamamen native yapıya geçirilmiştir.

Kullanılan teknolojiler: React Native, React Native Skia, Reanimated

Kişisel Hediye Web Sitesi

HTML, CSS ve JavaScript ile animasyonlu çiçekler, mektup alanı ve arka plan müziği içeren özel bir hediye sitesi geliştirdim.

Kullanılan teknolojiler: HTML, CSS, JavaScript

3D Küre Etkileşim Projesi

Three.js ile 3D küre modeli üzerinde bağlantı benzeri görsel bir etkileşim denemesi yaptım. Web ortamında 3D nesnelerle çalışma mantığını öğrendim.

Kullanılan teknolojiler: Three.js, JavaScript

Grid Tabanlı Oyun / UI Çalışmaları

Block Blast tarzı 6x6 ve 8x8 grid mantığıyla UI hizalama ve oyun panosu yerleşimi üzerine çalışmalar yaptım.

Kullanılan teknolojiler: HTML, CSS

Java Konsol Uygulamaları

Ortalama hesaplama, basamak sayısı bulma, tek/çift kontrolü ve kullanıcı giriş doğrulama gibi birden fazla mini Java projesi yaptım.

Kullanılan teknolojiler: Java
